# The hint ladder (learning work)

Source: decision TL5 in the vault's `decisions.md`.

Start on rung 1. Climb **one rung** only when Ashley asks for the next hint.

1. Ask a question that points at the gap.
2. Name the concept and link the official docs (Microsoft Learn for .NET).
3. Describe the shape of the solution in plain words or pseudocode, not C#.
4. Give a snippet of 5 lines or fewer, and only after she has shown her own attempt. She types it in herself.

## Allowed at any rung
- Explain an error message.
- Review her code against `principles.md`.
- Quiz her.
- Make up a drill.
- Run `/review-me` or `/teach-back`.

## Chores (🔧)
Setup outside the slice's learning target: the CI workflow, deploy config, `.gitignore`, `Directory.Build.props`, `.editorconfig`. You may draft it. Before she commits, walk her through it line by line until she can explain each line back to you.
